# inisie

> 深夜自販機前の小さなHP

自室から、ゆるく世界につながるための個人サイトです。  
「完成されすぎない」ことを大切に、日記や好きなもの、旅先の街、もちもの、写真などを少しずつ記録しています。

[公開サイトを見る](https://keisan-tsukuru.github.io/inisie/)

## ページ

- **トップ**：この場所についての案内と、今日のBGM
- **日記**：日々の短い記録と月別アーカイブ
- **好きなもの**：今の自分の「好き」
- **もちもの**：生活と冒険を支える道具
- **写真**：残しておきたい景色
- **まち**：歩いて、見て、少し好きになった街
- **リンク集**：お気に入りの場所
- **更新履歴**：サイトが育ってきた記録

## つくり

HTML、CSS、JavaScriptだけで作った、依存関係のない静的サイトです。  
GitHub Pagesで公開しています。

```text
index.html       トップ
diary.html       当月の日記
diary-YYYY-MM.html 過去の月の日記
favorites.html   好きなもの
mochimono.html   もちもの
photos.html      写真
machi.html       まち
links.html       リンク集
history.html     更新履歴
styles.css       共通スタイル
script.js        共通スクリプト
assets/          写真などの素材
```

## ローカルで見る

リポジトリを取得したあと、次のコマンドで簡易サーバーを起動できます。

```bash
python -m http.server 8000
```

ブラウザで [http://localhost:8000](http://localhost:8000) を開いてください。

## 更新するとき

- 日記や各ページの記録は、対応するHTMLへ直接追加します。
- メニュー項目を増やす場合は、すべてのHTMLのナビゲーションをそろえます。
- 公開用の写真は軽量化し、`assets/photos/`へ置きます。
- 目に見える追加は、必要に応じて`history.html`にも残します。

### 日記の月替わり

日々の追記は `diary.html` の先頭へ追加します。月の切り替えは、その月の最初の日記を追加するときに行います（自動切り替えはしません）。

1. それまでの `diary.html` を `diary-YYYY-MM.html` として保存します。
2. `diary.html` のタイトル・見出し・本文を新しい月へ更新します。
3. 直前の月のページから新しい月へ移動できるようにし、古い月から直前の月へ向く `diary.html` リンクは、その月の固定ファイル名に変更します。
4. 日記の全ページで「月ごとの日記」を更新し、最新月だけを `diary.html` に向けます。現在のページだけに `aria-current="page"` を付けます。
5. 前後の月へのリンクと月別一覧を確認します。記録のない月のページは作らず、記録のある隣の月へつなぎます。
